ap-advisor

A Codex Skill that uses learner evidence to diagnose, review, generate, and prioritize AP Precalculus / Calculus AB / BC study work. 一个根据学习者作答证据诊断、审阅、生成并安排 AP Precalculus、AP Calculus AB/BC 学习任务优先级的 Codex Skill。

View on GitHub 查看 GitHub 仓库

What it does功能介绍

  • Separates conceptual, modeling, procedural, representation, justification, reading, and pacing problems from actual response evidence.
  • Prioritizes one to three interventions, each with a reason, concrete practice method, measurable exit standard, and unseen transfer retest.
  • Maps generated content and recommendations to an internal Unit/Topic catalog — e.g. Unit 2, Topic 2.4 — Exponential Function Manipulation.
  • Keeps observable learning difficulty separate from instructional or exam-oriented scope.
  • Validates every displayed Topic mapping and reports when automated validation is NOT RUN.
  • 从真实作答证据区分概念理解、建模、程序计算、表示转换、数学论证、读题和时间管理问题。
  • 优先给出一至三个干预任务，每项包含理由、具体练法、可测退出标准和未见迁移复测。
  • 把生成内容和建议映射到内部 Unit/Topic 目录，例如 Unit 2, Topic 2.4 — Exponential Function Manipulation。
  • 把可观察的学习难度与教学型或面向考试的范围分开表达。
  • 展示前校验每个 Topic 映射，并在自动校验未运行时明确报告 NOT RUN。

Install安装方式

Clone the repo, then copy it into your Codex skills directory: 克隆仓库，然后把它复制到 Codex 的 skills 目录下： 

git clone https://github.com/iyorixy/APadvisor.git ap-advisor

# Codex
mkdir -p ~/.agents/skills
cp -r ap-advisor ~/.agents/skills/ap-advisor
# or, for a project-local skill:
mkdir -p .agents/skills
cp -r ap-advisor .agents/skills/ap-advisor

Requires Python 3.10+ (standard library only) on the machine running the agent, for the Topic-mapping validator. 运行 agent 的机器上需要 Python 3.10+（仅用标准库），用于运行 Topic 映射校验脚本。

Why this exists为什么做这个

Accuracy alone does not reveal a root cause. AP Advisor uses written work, error patterns, time, confidence, deadlines, and available study time to choose a small measurable intervention; it does not claim mastery before an unseen transfer retest. Topic mapping is a safety guardrail, not the product goal. 单看正确率不能说明根因。AP Advisor 结合书面作答、错误模式、耗时、信心、截止时间和可用学习时间，选择最小且可测的干预；完成未见迁移复测前不声称已经掌握。Topic 映射是安全护栏，不是产品目标。

The Unicode-aware validator checks normalized exact internal labels and topic-level catalog scope. Internal labels are not official-source citations. Human-facing prose says exam-oriented; legacy machine tokens such as ap-oriented mean only that every mapped Topic is marked assessed. They do not prove mathematics, topical fit, question type, calculator conditions, representation mix, rubric or scoring, or complete exam alignment. 支持 Unicode 的校验器只检查规范化精确内部标签和 Topic 层级目录范围。内部标签不是官方来源引用。面向用户的文案使用“面向考试”；兼容机器 token ap-oriented 只表示所有映射 Topic 均标记为 assessed，不证明数学、内容与 Topic 的适配、题型、计算器条件、表示形式、rubric、计分方式或完整考试对齐。
