ap-advisor

A Codex Skill that generates, reviews, and prioritizes AP Precalculus / Calculus AB / BC study content using a bundled citation catalog. 一个 Codex Skill，使用仓库内的引用目录生成、审阅和安排 AP Precalculus、AP Calculus AB/BC 学习内容。

View on GitHub 查看 GitHub 仓库

What it does功能介绍

  • Labels generated content with a Unit/Topic from the bundled citation catalog — e.g. Unit 2, Topic 2.4 — Exponential Function Manipulation.
  • Keeps learning difficulty separate from instructional or AP-oriented style.
  • Explanations state the underlying principle before any application, and include an application when it materially helps.
  • Given weak topics and/or an exam date, produces a suggested review order for the learner to evaluate.
  • Checks every citation label before showing it, normally with the bundled script, and reports when automated validation cannot run.
  • 每次生成内容都会标注仓库引用目录中的 Unit/Topic，例如 Unit 2, Topic 2.4 — Exponential Function Manipulation。
  • 把学习难度与教学型或 AP-oriented 风格分开表达。
  • 讲解内容先讲原理；实际应用场景只在确实有助于理解时加入。
  • 根据你指出的薄弱知识点和/或考试日期，给出一份需要由学习者评估的复习顺序建议。
  • 展示引用前检查每个引用标签；正常使用仓库脚本，并在自动校验无法运行时明确报告。

Install安装方式

Clone the repo, then copy it into your Codex skills directory: 克隆仓库，然后把它复制到 Codex 的 skills 目录下： 

git clone https://github.com/iyorixy/ap-advisor.git

# Codex
mkdir -p ~/.agents/skills
cp -r ap-advisor ~/.agents/skills/ap-advisor
# or, for a project-local skill:
mkdir -p .agents/skills
cp -r ap-advisor .agents/skills/ap-advisor

Requires Python 3.10+ (standard library only) on the machine running the agent, for the citation validator script. 运行 agent 的机器上需要 Python 3.10+（仅用标准库），用于运行引用校验脚本。

Why this exists为什么做这个

Ask a generic AI agent to "make me some AP Calc practice problems" and you may get course-scope mixups or invented Unit/Topic labels. AP Advisor checks citation labels against an internal catalog before presenting them. The validator proves exact catalog matching and topic-level scope only; it does not independently prove mathematical correctness, topical fit, learning-objective coverage, exclusions, task format, or calculator conditions. 让一个普通的 AI 助手“帮我出几道 AP 微积分练习题”，可能会遇到课程范围混用或凭空捏造 Unit/Topic 标签。AP Advisor 会在展示前根据内部目录检查引用标签。校验器只能证明目录精确匹配和 Topic 层级范围；它不能独立证明数学正确、内容符合所引 Topic，也不能证明 Learning Objectives、排除项、题型或计算器条件全部满足。

Machine-readable validator evidence binds the selected course and AP-oriented mode to every exact citation and topic scope. A command merely starting is not treated as a passing validation. 机器可读的校验证据会把所选课程与 AP-oriented 模式绑定到每条精确引用及其 Topic 范围；仅仅启动过命令不会被视为校验通过。
